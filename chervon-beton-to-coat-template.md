## Structural-пальто «Фасад» (Look 01)

## 1. Общая информация

| Параметр | Значение |
|---|---|
| Название модели | Structural-пальто «Фасад» |
| Категория | Верхняя одежда, унисекс/мужской крой |

| Сезон | Демисезон/зима |

## 2. Описание силуэта

Длинное однобортное пальто прямого силуэта, длина миди (ниже середины икры). Архитектурное плечо с кантилеверной панелью — плечевая линия слегка выступает за естественную линию плеча, создавая геометричный, скульптурный объём, отсылающий к выступающим элементам фасада панельного дома.

Геометричный воротник со строгой прямой кромкой, стойка. Полочка застёгивается по диагонали — не по центру, а со смещением, создавая асимметричную линию борта.

**Ключевая деталь:** ниже линии бедра диагональный разрез/шов полочки открывается, обнажая подкладку глубокого красного цвета — как проступающая «трещина» в сером фасаде. Разрез оформлен чистым срезом без дополнительной отделки, край окантован в цвет подкладки.

Спинка разделена горизонтальным швом-кокеткой на два тональных блока серого (светлый верх / более тёмный низ или наоборот) — имитация стыков бетонных панелей.

## 3. Детали и фурнитура

- Воротник: стойка, геометричный срез, без лацканов
- Застёжка: скрытая, на кнопках или крупных пуговицах в тон ткани (уточнить у конструктора после примерки)
- Карманы: два прорезных кармана с клапаном, без лишней отделки
- Вышивка: геометричный орнамент (ромб/крест, модульный повтор), размещение — асимметрично на спине сверху, размер ~15×20 см (уточнить после образца)
- Подкладка: полностью — глубокий красный, видна через диагональный разрез спереди

## 4. Спецификация материалов

| Материал | Назначение | Состав/примечание |
|---|---|---|
| Шерстяной мелтон, серый, матовый | Верх | Плотность и вес — уточнить после теста образца |
| Шерстяная фланель/букле, красный | Подкладка (видимая часть) | Глубокий, приглушённый оттенок `#A32D2D` |
| Подкладочная ткань, красная (более лёгкая) | Подкладка (скрытая часть рукавов и т.п.) | Для снижения себестоимости на невидимых участках |
| Флизелин/дублерин | Уплотнение плеча, воротника | Для сохранения формы кантилеверной панели |
| Нитки для вышивки | Орнамент | Тёмно-красный + чёрный |
| Пуговицы/кнопки | Застёжка | Матовые, тон в тон с верхом |

## 5. Технологические примечания

- Перед раскроем финальной ткани — обязателен пробный пошив макета из недорогой ткани (бязь/муслин) для проверки посадки кантилеверного плеча
- Край диагонального разреза требует чистой обработки (окантовка или подгиб) — не должен осыпаться при носке
- Совпадение рисунка вышивки по шву кокетки — контрольная точка при финальной проверке качества
- Расход ткани на единицу — уточнить у производства после утверждения лекал

## 6. Контрольные точки качества

- [ ] Плечевая линия симметрична (или намеренно асимметрична — уточнить по эскизу)
- [ ] Диагональный разрез открывается ровно, без перекоса
- [ ] Красная подкладка видна в заданном объёме, не топорщится
- [ ] Вышивка/орнамент ровный, без затяжек нити
- [ ] Кокетка спины — швы совпадают по цвету блоков как задумано
